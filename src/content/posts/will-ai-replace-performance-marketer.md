결론부터 말하면, **퍼포먼스 마케터의 일은 줄어드는 게 아니라 옮겨 가고 있습니다.** 손으로 하던 최적화는 AI가 가져갔고, 사람에게는 "AI에게 무엇을 시키고, 그 결과를 믿어도 되는지" 판단하는 일이 남았습니다.

## AI로 자동화되고 있는 업무

몇 년 전까지 사람이 직접 하던 일 중 상당 부분을 이제 매체의 자동화 기능이 맡습니다.

| 업무 | 예전 방식 | 지금 |
|---|---|---|
| 입찰 | 키워드·광고별로 입찰가를 직접 조정 | 목표(전환, 전환당 비용, ROAS)만 정하면 매체가 입찰 |
| 타깃팅 | 연령·관심사·지역을 하나씩 설정 | 넓게 열어 두고 매체가 반응할 사람을 찾음 |
| 소재 조합 | 제목·이미지·문구 조합을 사람이 만들어 테스트 | 여러 요소를 넣으면 매체가 조합하고 골라 노출 |
| 캠페인 구조 | 매체·지면별로 캠페인을 잘게 쪼갬 | 하나의 캠페인이 여러 지면에 알아서 배분 |
| 리포트 정리 | 매체별 숫자를 엑셀로 모아 정리 | 대시보드·AI 요약으로 자동 정리 |

대표적인 예가 구글의 **실적 최대화(Performance Max, PMax)** 캠페인과 메타의 **어드밴티지+(Advantage+)** 기능입니다. 둘 다 목표와 재료(예산, 소재, 데이터)를 주면 지면, 타깃, 입찰을 매체가 정하는 방식입니다([구글 실적 최대화 도움말](https://support.google.com/google-ads/answer/10724817?hl=ko)). 국내 매체에도 네이버의 ADVoost 쇼핑, 카카오모먼트의 전환 최적화처럼 비슷한 자동화 상품이 있습니다([네이버](https://ads.naver.com/help/faq/1374), [카카오](https://kakaobusiness.gitbook.io/main/ad/moment/intro/run/optimization)).

### 자동화 입찰은 어떻게 배울까?

먼저 광고가 노출되는 원리부터 보면, 광고 자리는 **경매**로 정해집니다. 구글 검색광고는 입찰가와 광고 품질 등을 함께 따져 광고 순위를 정하고([구글 광고 경매](https://support.google.com/google-ads/answer/6366577?hl=ko)), 그래서 같은 돈을 내도 품질이 낮으면 덜 노출됩니다. 노출이 줄었다면 **검색 수요가 줄었는지, 예산이 일찍 바닥났는지, 경쟁에서 밀렸는지, 광고가 멈췄는지**를 따로 봅니다. 구글은 예산 때문에 놓친 노출과 순위 때문에 놓친 노출을 나눠 보여 줍니다([노출 점유율](https://support.google.com/google-ads/answer/2497703?hl=en)).

자동화 입찰은 이 경매에서 입찰가를 대신 정합니다. 목표는 크게 둘입니다. **전환 수**를 늘리는 쪽(전환수 최대화, 타깃 CPA)과 **전환 가치(매출)**를 늘리는 쪽(전환 가치 극대화, 타깃 ROAS)입니다([구글 스마트 자동 입찰](https://support.google.com/google-ads/answer/7065882?hl=ko)). 객단가 차이가 큰 쇼핑몰이라면 건수보다 가치를 목표로 하는 편이 맞을 수 있습니다.

자동화 입찰은 **지난 전환 데이터**를 보고 "어떤 사람, 어떤 지면, 어떤 시간에 전환이 잘 나는지"를 배웁니다. 그래서 두 가지 특징이 있습니다.

- **바꾸면 다시 맞춰 가는 시간이 필요하다**: 새 캠페인을 만들거나 입찰 전략, 목표, 캠페인 구조를 크게 바꾸면 매체가 새 조건에 맞춰 가는 동안 숫자가 흔들립니다. 구글은 큰 변경 뒤 학습 상태 표시가 보통 7일 안에 사라지고, 성과는 전환이 일어나기까지 걸리는 기간의 1~2배에 걸쳐 새 목표에 맞춰진다고 안내합니다([구글 스마트 입찰 학습](https://support.google.com/google-ads/answer/13020501?hl=en)). 그 사이 자주 손대면 맞춰 가는 시간이 계속 늘어납니다.
- **전환이 충분해야 한다**: 배울 재료가 적으면 잘못 배웁니다. 얼마나 있어야 충분한지는 매체마다 기준이 달라서, 쓰는 매체의 도움말에서 확인합니다.

<!-- 확인할 것: 메타 학습 단계 기준(광고 세트당 7일 약 50건으로 알려짐)은 현재 공식 기준으로 확인 못 함. 넣으려면 메타 도움말로 확인 -->

그래서 자동화가 **잘 맞지 않는 때**도 있습니다.

| 이런 때 | 이유 |
|---|---|
| 전환이 아주 적을 때 | 배울 데이터가 부족함. 클릭처럼 더 자주 일어나는 행동을 먼저 목표로 잡기도 함 |
| 전환 측정이 틀렸을 때 | 틀린 데이터를 빠르게 배움 |
| 며칠짜리 짧은 행사일 때 | 학습이 끝나기 전에 행사가 끝남 |
| 꼭 보여 줘야 할 대상이 정해져 있을 때 | 자동화는 전환이 잘 나는 쪽으로 쏠림 |

생성형 AI도 이 흐름에 더해졌습니다. 광고 문구 초안, 이미지 변형, 리포트 요약처럼 시간이 많이 들던 작업이 빨라졌습니다.

## 자동화하기 어려운 판단과 의사결정

사람에게 남는 판단은 네 가지입니다. **무엇을 목표로 할지, 데이터를 믿어도 되는지, 무엇을 재료로 넣을지, 결과를 어떻게 설명할지.** AI는 주어진 목표를 향해 가장 빨리 달리는 일은 잘하지만, 목표와 데이터가 맞는지는 스스로 묻지 않습니다.

### 1. 무엇을 목표로 할지 정하는 일

AI에게 "전환을 늘려라"라고 하면 전환을 늘립니다. 그 전환이 비싼 상품 구매인지, 바로 환불될 구매인지, 다시 오지 않을 고객인지는 따로 알려 주지 않으면 구분하지 않습니다. **어떤 결과를 '좋은 결과'로 셀지**는 사업을 아는 사람이 정해야 합니다. 업종마다 기준이 다릅니다.

| 업종 | 단순히 세면 | 좋은 전환으로 보려면 |
|---|---|---|
| 커머스 | 구매 건수 | 신규 구매인지, 마진, 반품·취소 |
| 상담·문의(리드) | 문의 건수 | 유효한 상담, 실제 계약까지 (고객 관리 시스템에서 확인) |
| 앱 | 설치 수 | 설치 뒤 활성 사용, 유료 전환, 재방문 |

문의 100건과 60건 중 어느 쪽이 나은지는 계약까지 이어진 건수를 봐야 답할 수 있습니다. 구글은 이렇게 오프라인 결과를 광고에 다시 연결하는 방법도 안내합니다([리드 전환 측정](https://support.google.com/google-ads/answer/11347292?hl=en)).

### 2. 데이터를 믿어도 되는지 확인하는 일

자동화는 들어온 데이터를 그대로 믿고 학습합니다. 전환이 두 번 잡히거나, 테스트 주문이 섞이거나, 태그가 빠지면 AI는 틀린 방향으로 빠르게 학습합니다. EP.02에서 세팅을 "가장 조심하는 단계"라고 한 이유가 여기서 더 커집니다.

> **예시 상황.** 구매를 목표로 하는 자동화 캠페인의 전환이 갑자기 두 배로 늘었습니다. 좋아할 일 같지만, 매출은 그대로였습니다. 확인해 보니 사이트를 고치면서 "장바구니 담기"에도 구매 태그가 붙어 버렸습니다. 매체는 장바구니만 담고 사지 않는 사람을 "구매자"로 배워, 그런 사람에게 광고를 더 보여 주고 있었습니다. 운영자는 이렇게 풀어 갑니다. 전환은 늘었는데 매출이 그대로인 걸 보고 **쇼핑몰 주문 원본과 매체의 구매 이벤트 수를 날짜별로 대조**합니다. 차이가 사이트 개편 날부터 생긴 걸 확인하고, 그동안은 예산 증액과 소재 교체를 **보류**합니다. 태그를 고친 뒤 테스트 주문을 넣어 구매 한 건이 한 번만 기록되는지 확인하고, 며칠 동안 주문 수와 구매 이벤트 수가 다시 맞는 걸 본 다음에야 운영 판단을 다시 시작합니다. 매체가 새로 맞춰 가는 동안 숫자가 흔들리는 것도 이때 감안합니다.

### 3. 무엇을 넣을지 고르는 일

자동화가 소재를 조합해 주지만, 조합할 재료는 사람이 넣습니다. 어떤 메시지로 누구를 멈추게 할지, 브랜드가 하지 말아야 할 말은 무엇인지는 매체가 대신 정해 주지 않습니다.

### 4. 결과를 설명하고 책임지는 일

"AI가 그렇게 했다"는 광고주나 상사에게 설명이 되지 않습니다. 왜 숫자가 바뀌었는지, 다음 달에 무엇을 바꿀지 말하고 결정에 책임지는 일은 여전히 사람의 몫입니다.

## 그래서 앞으로 필요한 퍼포먼스 마케터는

정리하면 일의 무게중심이 이렇게 옮겨 가고 있습니다.

| 줄어드는 일 | 커지는 일 |
|---|---|
| 입찰가·타깃을 손으로 조정 | 목표와 판단 기준을 설계 |
| 소재 조합을 하나씩 테스트 | 넣을 메시지와 재료를 기획 |
| 숫자를 모아 정리 | 숫자가 맞는지 검증하고 해석 |
| 매체 화면을 잘 다루는 것 | 매체 밖 사업을 이해하는 것 |

AI가 잘 달리게 할수록, **어디로 달릴지 정하는 사람**의 실력이 결과를 가릅니다.
